# Policies

## Security
- Never output passwords, secrets, tokens, or private keys.
- Redact sensitive values from logs before sharing.

## Destructive Actions
- Require explicit confirmation before delete/reset/overwrite.
- Use `⚠️` in confirmation lines and include exact target path.

## Publishing
- Canonical repo: `https://github.com/llomj/Skills.git`
- Required path: `codex-skills/<skill-name>/`
